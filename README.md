# ゆもつよメソッドのAIエージェントスキル

ゆもつよメソッドを基礎に、仕様書・要件書・設計書からテスト要求分析（TRA）、テストアーキテクチャー設計（TAD）、テスト詳細設計（TDD）、テスト実装（TI）を一貫して行うためのAIエージェントスキルです。

現在のバージョン：**0.83**

このリポジトリでは、スキル本体を無償公開しています。理論的な背景、設計判断、作成過程については、[noteの「ゆもつよメソッド」マガジン](https://note.com/yumotsuyo/m/maa0d15fb27e8)で解説しています。

## 特徴

- 仕様書からすぐにテストケースを列挙せず、対象をモデル化してからテスト分析・設計へ進みます。
- 仕様書の章や画面をそのまま機能一覧にせず、分散した仕様を「テストとして意味のある塊」に再構成します。
- 対象理解モデルをMermaidで可視化し、人によるレビューを必須工程にします。
- 論理的機能構造とテストカテゴリを使い、欠陥仮説を明示します。
- 仕様項目からテスト詳細設計、テストプロシジャーまでトレーサビリティを保ちます。

## ワークフロー

```text
テストベース
  → 対象理解モデル（人による承認）
  → 機能一覧
  → 論理的機能構造
  → テストカテゴリ・欠陥仮説
  → テスト分析マトリクス
  → リスク分析・厚み調整
  → 仕様項目
  → TDD
  → TI
  → テスト実行
```

## インストール

`yumotsuyo-test-development`フォルダを、利用するAIエージェントのスキル配置先へコピーしてください。

Codexでは、スキルの配置後に次のように指定して利用できます。

```text
$yumotsuyo-test-development
この仕様書を対象に、対象理解モデルからテスト分析・設計を行ってください。
対象範囲は〇〇機能です。成果物はMarkdownで保存してください。
```

プロンプト例は [`references/prompt-examples.md`](yumotsuyo-test-development/references/prompt-examples.md) を参照してください。

## 利用上の注意

このスキルは品質を保証するものではありません。入力されたテストベースの完全性・正確性、対象固有の専門知識、実行環境によって結果は変わります。特に、対象理解モデル、仕様未定義事項、リスク判断は人がレビューしてください。

性能、セキュリティ、ユーザビリティ、コードカバレッジ中心のコンポーネントテスト、安全性、法規制を中心とする対象は、このスキルだけで完結させず、専用のモデルや技法を追加してください。
